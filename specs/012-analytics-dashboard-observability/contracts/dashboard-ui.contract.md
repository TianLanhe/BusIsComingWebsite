# Dashboard 可观测性 UI 行为契约

本文件约束 OpenAPI 无法表达的浏览器交互、信息架构、比较语义、三语和响应式行为。私有服务端
字段以 [analytics-monitoring-api.openapi.yaml](analytics-monitoring-api.openapi.yaml) 为权威，
视觉和交互以 [Figma v1.3 节点 89:1310](https://www.figma.com/design/LAm6RjzFuFHsHFlcipx8pU/BusIsComing-Website---Homepage-v1-Spec?node-id=89-1310)
为主要参考。011 已实现的公开 Vite `/` 重定向继续保持，本功能不改变其行为。

## 1. 全局日期范围与两步状态

### 1.1 稳定状态

| 状态 | 右上角 | 高级筛选 | 请求 |
|------|--------|----------|------|
| 预设 7/30/90 天 | 显示预设名称 | 显示实际开始和结束日期 | 使用已求值香港范围 |
| 自定义已应用 | 显示完整起止日期 | 两个日期字段与右上角一致 | 使用已应用范围 |
| 选择开始日期 | 显示“选择开始日期” | 不覆盖已应用日期 | 不发起 |
| 选择结束日期 | 显示“开始日期 – 选择结束日期” | 不覆盖已应用日期 | 不发起 |
| 校验失败 | 保持流程和草稿 | 显示三语错误 | 不发起 |
| 取消 | 恢复已应用范围 | 恢复已应用日期 | 不发起 |

### 1.2 转换规则

1. 选择“自定日期”进入第 1/2 步，并在用户手势内调用开始输入框的 `showPicker()`。
2. 选定开始日期后进入第 2/2 步；可以尝试打开结束输入框。浏览器拒绝自动打开时，保留明确的
   一次点击继续入口，不回退为无动作状态。
3. 选定合法结束日期后一次性提交开始和结束日期，只触发一次全局刷新。
4. `Escape`、点击外部或取消只清除草稿，不修改当前已应用范围。
5. 开始晚于结束、任一日期无效或晚于香港当天时，在查询前阻止应用。
6. 右上角和高级筛选使用同一 `DateRangeSelection` 权威状态；不得各自维护已应用日期副本。
7. 切换预设、高级筛选应用自定义范围、语言、页面或手动刷新后，两处日期继续同步。

### 1.3 展示

- 桌面端显示两个完整日期，例如 `2026/07/01 – 2026/07/24`。
- 跨年范围始终显示两个完整年份。
- 手机可缩短同年范围的可见文案，但无障碍名称必须保留完整起止年份。
- 所有日期按 `Asia/Hong_Kong` 解释；固定历史范围刷新不漂移，包含今天的范围刷新时推进 `to`。

## 2. 单一 Tooltip

### 2.1 输入方式

- 鼠标/触控指针由 Recharts `<Tooltip>` 负责。
- 键盘聚焦数据点由自定义无障碍 Tooltip 负责。
- 图表状态显式记录最近输入方式 `pointer | keyboard | null`。
- 指针移动到有效时间桶时清除键盘 active index；键盘聚焦时抑制 Recharts 可见 Tooltip。
- 数据点失焦、指针离开或数据/序列改变时清理相应状态。

### 2.2 不变量

- 任意图表、任意时刻最多一个可见 Tooltip 和一条参考线。
- 鼠标与键盘 Tooltip 共用日期、序列顺序、数值和单位格式化函数。
- Tooltip 一次展示当前时间桶和全部可见序列；没有样本显示无数据，不显示 0。
- 图例位于图表上方或下方；图表底部不得显示可见摘要或大段数据转储。
- `sr-only` 数据表继续向辅助技术提供完整时间桶和实际序列。

## 3. 比较状态

当前值、上一周期值、绝对变化、变化率和全局 compare 开关共同派生以下互斥状态：

| 状态 | 条件 | 文案与数值 |
|------|------|------------|
| `increased` | 两期有样本且 delta > 0 | 向上箭头、带 `+` 数值、同期文字 |
| `decreased` | 两期有样本且 delta < 0 | 向下箭头、带 `-` 数值、同期文字 |
| `unchanged` | 两期有样本且 delta = 0 | “与上期无变化” |
| `zero_baseline` | 上期为 0、当前大于 0 | 绝对变化，不显示无穷百分比 |
| `no_previous` | 上期无样本 | “暂无同期数据” |
| `no_current` | 当前无样本 | 主值和比较均显示无数据 |
| `disabled` | compare=false | “未启用同期比较” |

- 普通数量增加/减少使用中性方向语义。
- 失败事件增加为恶化、减少为改善。
- 时延增加为恶化、减少为改善。
- 颜色不是唯一线索，必须同时提供方向、带符号数值和文字。

## 4. 导航与页面命名

| 分组 key | 页面 |
|----------|------|
| `businessMonitoring` | 总览、流量与试查、下载分析 |
| `technicalMonitoring` | 稳定性 & 时延、系统状态 |
| `dataDetails` | 事件明细、访客明细 |

- 原“失败与性能”统一改为“稳定性 & 时延”。
- 原“匿名访客”统一改为“访客明细”。
- 桌面侧栏、移动抽屉、移动底部导航和页面标题使用相同路由与三语 key。
- 移动底部导航可以使用三个分组入口；进入分组后必须可到达全部七个页面。

## 5. 页面行为

### 5.1 事件明细

- 四张卡依次为筛选结果、成功事件、失败事件、独立访客。
- 四卡使用完整筛选范围和同一上一等长周期，不受当前 50 条分页与 cursor 影响。
- 每张卡遵守第 3 节全部比较状态；失败卡使用失败方向语义。
- 桌面表格、手机事件卡、完整 Visitor ID header 筛选、复制/跳转和分页继续可用。

### 5.2 流量与试查

- 顶部依次展示主页浏览 PV/UV、地点查询 PV/UV、路线查询 PV/UV 六张卡。
- 地点和路线 PV 包含成功与失败；三项 UV 分别按匿名 Visitor ID 在完整筛选范围去重。
- 既有“浏览与成功试查趋势”只保留主页 PV、主页 UV、成功路线查询 UV 三条序列。

### 5.3 稳定性 & 时延

- 顶部六卡：总请求、成功率、P50、P95、失败请求、Dropped。
- P50/P95 主值和变化值都明确使用 `ms`；Dropped 的 system 辅助查询失败时只局部降级。
- 响应时间趋势拥有局部 `P50 | P95` 选择器，默认 P95；切换只改变本图。
- 响应时间趋势按主页、地点、路线、下载绘制四条事件序列，无样本桶断线。
- SLI 图按四类事件绘制 `成功 PV / 总 PV`；`总 PV=0` 的点为空，不能绘制成 0%，不得增加
  目标线或称为 SLA。
- 公开接口效能表增加 P50/P95 较上期两列，并覆盖第 3 节比较状态。

### 5.4 系统状态

- 只保留“SQLite 明细存储”一个存储主区块，删除重复“存储概况”和“隔离与降级路径”。
- SQLite 明细存储显示总明细数、香港今日明细数、主数据文件大小、最后成功写入。
- SQLite 运行信息显示 SQLite 版本、Journal Mode、Schema 版本。
- 服务运行信息显示进程启动、运行时长、Dropped、私有监听器状态和地址。
- SQLite、进程或监听器的任一用户可见字段缺失时只让该项显示无数据，其他已取得字段继续展示；
  `publicProxy=false` 是固定隐私事实，不显示为可空探测项。
- 不展示数据库绝对路径、密钥、客户端网络标识、请求内容或内部错误原文。

### 5.5 访客明细

- 四张摘要卡严格依次为首次出现、最后出现、会话、累计事件。
- “访客偏好”只展示最常见语言、平台和装置；并列时使用服务端稳定顺序。
- 平台只来自下载事件归因，没有下载样本时显示“暂无平台数据”。
- 事件构成、22 位完整 ID 搜索、复制反馈、返回事件明细和 30 分钟会话时间线继续可用。

## 6. 三语、响应式和可访问性

- 新增/修改 key 在 `zh-Hant`、`zh-Hans`、`en` 同时存在。
- `zh-Hant` 使用香港监控产品常见书面语；英文使用自然克制的产品表达，不从简体中文逐句直译。
- 语言切换保持当前页面、已应用日期、日期选择步骤、全局筛选、P50/P95 选择和调查 Visitor。
- 1440×1200：六列指标、双图并排和端点语义表格无截断。
- 390×844：卡片按两列/单列重排，端点表转为可读卡片或局部语义滚动，不整体缩放桌面表格。
- 页面不得整体横向滚动；已有逐日热力图绘图区可以局部横向滚动。
- 日期、分位选择、导航、刷新、分页和 Visitor 操作触控目标至少 44px。
- loading、no_data、no_results、query_failed、storage_unavailable 与局部字段无数据互斥且文案不同。

## 7. 隐私与发布

- UI 不展示客户端或事件来源 IP、完整 UA/Referrer、查询内容、数据库路径、签名密钥或原始错误；
  系统状态只允许展示 OpenAPI 规定的 `127.0.0.1:<port>` loopback 监听地址。
- 不以设计示例、旧缓存或 0 掩盖缺失响应。
- 不新增公开/私有 endpoint、事件类型、汇总表、缓存、队列、后台聚合、备份、清理、导出、
  删除或编辑能力。
- 私有后端与 `frontend/dist-monitor` 作为同一发布物原子升级和整体回滚。
