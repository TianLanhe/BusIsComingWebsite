# Dashboard UI 与本地入口行为契约

本文件约束不能由 OpenAPI 表达的公开 Vite 根路径、全局日期选择、指标卡、图表、响应式和局部降级行为。私有服务端字段以 `analytics-monitoring-api.openapi.yaml` 为权威。

## 1. 公开 Vite 根路径

### 适用范围

- 公开主页 `frontend/vite.config.ts` 的 dev server。
- 公开主页 `frontend/vite.config.ts` 的 preview server。

### 请求矩阵

| 方法 | pathname | 预期 |
|------|----------|------|
| GET | `/` | `302 Found`，`Location: /zh-hant/`，结束响应 |
| HEAD | `/` | `302 Found`，`Location: /zh-hant/`，无响应体 |
| POST/PUT 等 | `/` | 不重定向，交给后续中间件 |
| 任意 | `/zh-hant/`、`/zh-hans/`、`/en/` | 不重定向 |
| 任意 | `/api/*`、静态资源、带本地化前缀的路由 | 不重定向 |

监控 `vite.monitor.config.ts`、Go 正式静态托管和 Caddy 不安装此插件。

## 2. 全局日期范围

- 预设：7、30、90 个香港自然日，包含今天，截止每次求值的当前时刻。
- 自定义：开始和结束日期均包含；结束日期为今天时截止当前时刻，为历史日期时截止下一日 00:00。
- 日期错误在控件附近展示，错误存在时禁止请求。
- 手动刷新触发所有当前工作区重新求值；总览每次成功响应后 60 秒触发下一次重新求值。
- 详细工作区不自动刷新。
- 切换语言、工作区、筛选时保持日期选择；刷新失败时保持现有选择与筛选。

## 3. 指标卡

- 桌面指标 40px/760，手机 36px/760；长值允许收敛但不得低于 32px。
- 标签桌面 14px、手机 13px；可见辅助文字桌面不低于 13px、手机不低于 12px。
- 不渲染右上圆圈、右下光斑或其他会被理解为状态/操作的装饰。
- 比较状态必须从 Metric + compare 开关派生：
  - delta > 0：上升符号、带正号数值、同期文字。
  - delta < 0：下降符号、带负号数值、同期文字。
  - delta = 0：“较上期持平”。
  - previousValue = null：“暂无同期数据”。
  - compare = false：“未启用同期比较”。
- `value=null` 显示缺失状态，不能显示 0。
- 状态不能只依赖颜色。

## 4. 通用时间序列图

### 可见结构

1. 卡片标题和说明。
2. 绘图区上方完整图例。
3. Y 轴刻度与单位、X 轴香港时间刻度、低对比网格。
4. 各序列线、点和当前 active time bucket 十字线。
5. 浮动共享 Tooltip。

图表下方不得出现可见摘要或数据转储。

### 交互

- 鼠标进入某个时间桶或键盘聚焦该桶的数据点时，设置相同 active index。
- Tooltip 标题显示香港当地日期/时间，正文按图例顺序显示全部实际序列值。
- 键盘离开图表或鼠标离开绘图区后可隐藏 Tooltip；焦点样式清晰。
- 空数据渲染空状态，不绘制全零折线。
- 辅助技术通过 `sr-only` 表格读取标题、时间桶和全部序列值。

### 页面序列

- 总览/流量：主页 PV、主页 UV、成功路线查询 UV；页面可按用途选择其中子集，但图例必须与实际绘制一致。
- 性能：全局 P50、全局 P95，单位毫秒。

## 5. 逐日热力图

- 七行固定为周一到周日，周次从左到右。
- API 每个实际日期对应一个 cell；前端只补首尾周的空白占位。
- 色阶基于 eventCount，Tooltip 显示当地日期、eventCount、UV。
- 仅显示“少→多”强度图例。
- 范围较长时 `.heatmap-scroll` 内部横向滚动；卡片标题、说明、图例和页面不随之滚动。

## 6. 详细工作区结构

### 事件明细

- 页面级筛选：事件、结果、语言、设备、来源、日期、Visitor ID 调查入口。
- 隐私提示、四张完整范围摘要卡、桌面表格/手机卡、50 条分页。
- 表格列：时间、事件类型、截断 Visitor ID、语言、设备、来源、状态、耗时、查看访客。

### 匿名访客

- 完整 22 位 ID 搜索、复制反馈、返回事件明细、匿名浏览器解释。
- 首次、最后出现、会话数、累计事件四卡。
- 事件构成、常见语言/设备/来源/可空平台、30 分钟会话时间线。

### 失败与性能

- 总请求、成功率、失败请求、P50、P95、Dropped 六卡。
- P50/P95 时间序列、失败分类、端点性能表。
- system 辅助查询失败时只有 Dropped 卡进入局部不可用。

### 系统状态

- 数据库、最后写入、Dropped、私有监听器四张动态状态卡。
- 运行状态、存储概况、隔离与降级三个区块。
- 固定事实必须带“配置事实”标签；不得虚构写入队列。

## 7. 三语与响应式

- 所有新增 key 在 `zh-Hant`、`zh-Hans`、`en` 同时存在。
- `zh-Hant` 使用香港监控产品书面语；英文自然克制，不逐句机械翻译。
- 1440×1200：六列总览 KPI、语义表格、高密度图表。
- 390×844：两列/单列 KPI、纵向卡、key-value 事件卡、44px 操作目标。
- 页面不出现整体横向滚动；只有热力图绘图区允许横向滚动。

## 8. 失败与隐私

- loading、no_data、no_results、query_failed、storage_unavailable 互斥且文案不同。
- 重试保留日期、筛选、语言、工作区和 Visitor ID。
- 不以旧数据、设计示例或 0 掩盖缺失响应。
- UI 不展示 IP、完整 UA/Referrer、查询内容、数据库绝对路径、签名密钥或原始错误。
