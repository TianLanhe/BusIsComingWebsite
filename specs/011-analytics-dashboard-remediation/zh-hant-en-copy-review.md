## 指标比较状态

| 状态 | 简体中文 | 香港繁中 | 英文 |
|---|---|---|---|
| 数值无变化 | 较上期持平 | 與上期持平 | Unchanged from previous period |
| 上期无样本 | 暂无同期数据 | 暫無同期數據 | No previous-period data |
| 未开启比较 | 未启用同期比较 | 未啟用同期比較 | Period comparison off |
| 当前无样本 | 暂无当前数据 | 暫無目前數據 | No current data |

四种状态不会用 `--`、`0` 或只有颜色的符号代替语义；英文采用完整但克制的状态短语。

## 隐私与配置事实

- Visitor ID 明确为 HttpOnly Cookie 的通用传输信息，不进入 query 或 body；三语均明确不记录 IP。
- 事件页只列允许字段，并明确不含完整 UA/Referrer、查询词、地点、坐标或 token。这里没有声称“不使用 Cookie”，避免与匿名 Visitor ID Cookie 的事实冲突。
- “长期保留”“不备份”“无写入队列”“只保存明细并在查询时计算”均写成配置事实，不伪装成实时探测结果。
- 英文使用 `Backups are disabled; analytics data may be lost` 和 `Only event details are stored; aggregations run at query time`，直接表达约束及影响，不照搬中文句序。
- 香港繁中使用“只可經 SSH 隧道存取”“私人統計儲存”“數據目前無法讀取”等自然本地表达，不采用大陆书面语的逐字繁化。

## 状态与操作文案

- loading、所选范围无数据、筛选无结果、普通查询失败和存储不可用使用不同标题与说明。
- 失败文案明确筛选条件仍保留、内部错误不会展示；存储不可用文案明确公开主页、路线试查及 APK 下载仍可用。
- 英文按钮使用 `Refresh`、`Try again`、`Apply dates` 等直接动作，不使用冗长或过度正式表达。

## 审校结果

1. UV/PV、成功请求、下载响应与安装完成之间的边界表达清楚。
2. 匿名浏览器不被表述为自然人，隐私说明与实际 Visitor ID 传输方式一致。
3. 动态状态与固定配置事实的措辞明确分离。
4. 香港繁中与英文均按目标语境重写，未发现机械直译、含义漂移或缺失语种。
